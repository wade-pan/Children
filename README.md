# 🏆 潘翼芃 潘一柠任务小分队系统

**潘翼芃 潘一柠任务小分队系统** 是专为 **哥哥潘翼芃（五年级）** 与 **妹妹潘一柠（二年级）** 打造的家庭成长与任务发布系统。

核心包含 **“教妹妹围棋”** 专属大类教学专区、各学科每日任务布置、实时微信群播报生成器、任务打卡清单与小红花成长积分榜。

---

## 🌟 核心大类与功能模块

### 1. ♟️ 教妹妹围棋 (核心专区 · 首个大类)
- **小老师与学员角色**: 由哥哥 **潘翼芃 (五年级)** 担任围棋小老师，指导妹妹 **潘一柠 (二年级)**。
- **5 阶围棋体系化课程**:
  1. *第1阶段：气与吃子基础*（数气、打吃与提子、逃跑）
  2. *第2阶段：真眼与死活常识*（禁着点、真眼与假眼、两眼活棋）
  3. *第3阶段：常用吃子大绝招（手筋）*（双打吃、门吃、抱吃、枷吃、征子、接不归）
  4. *第4阶段：死活基础与比气对杀*（有眼杀无眼、公气与外气、大眼死活）
  5. *第5阶段：实战对弈与复盘礼仪*（9路盘实战对弈、金角银边草肚皮、复盘点拨）
- **教学打卡记录**: 记录哥哥教学内容、妹妹掌握情况星级评分（⭐⭐⭐⭐⭐），打卡成功自动为兄妹双方发放小红花 🌸 与星星积分 ⭐！
- **成长足迹历史**: 实时查看每一堂围棋课的对弈与复盘记录。

---

### 2. ✍️ 发布小分队任务 (微信播报实时排版)
- **任务定制**: 支持选择任务分类（教妹妹围棋、语文天地、数学探索、英语口语、体育运动、科学思维、每日阅读）、执行队员（潘翼芃/潘一柠/全员）、截止时间与小红花奖励。
- **📱 微信群实时预览模拟器**: 右侧同步生成精美排版的微信群通知文案，支持 **一键复制**，直接粘贴至家庭微信群。

---

### 3. 📋 今日任务与打卡清单
- 浏览当日与历史发布的所有任务卡片。
- 支持一键复制对应任务的微信播报文本或删除任务。

---

### 4. 🌸 小红花与成长星星积分榜
- **潘翼芃 (哥哥 · 五年级)**: 实时展示累积小红花与星星积分。
- **潘一柠 (妹妹 · 二年级)**: 实时展示累积小红花与星星积分。
- 支持手动表彰与增减红花。

---

### 5. 📑 任务快捷模板库
- 预置常用任务模板（围棋吃子教学、语文古诗背诵、数学口算与竖式计算、英语情景对话、一分钟跳绳等），**1秒引入，快速发布**。
